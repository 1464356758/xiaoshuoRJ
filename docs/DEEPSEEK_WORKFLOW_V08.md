## 从参考图改成实际软件

1. **全书骨架与首批详纲**：DeepSeek策划，先比较不同故事发动机、读者体验和差异；新增核心规则与人物行为/改变条件。先验证开篇，后续最多十章一批滚动规划，避免90万字盲跑。
2. **章节任务书**：同一策划请求写读者已知/期待/当章回报/后续承接，逐场景写停点stopAfter与保留事件defer，继续保留因果、主动选择、代价、知情边界、必须/禁止变化与伏笔行动。
3. **DeepSeek正文**：按任务书读取当前锁定事实、最近及相关旧稿原文/哈希，以及最多四名相关人物最近选择与最后已成立转变。一个剧情单元可跨多个保存分段，不要求每1600字从头完成一次高潮。保留原9000字目标与可调分段，未自动改成图中2500–3000字。
4. **独立审核**：建议Qwen，既有保存的审核配置不被本轮切换改动。免费预检→单章全文审稿→可局部修复才补丁→再次全文审稿→锁定。新增人物/世界/逐场景边界的实际引文；引文程序验证不等于语义已被机器证明。
5. **三章/十章关口**：原有联合全文审核继续，检查阅读回报、人物演变、因果后果与重复；失败不写后章、不因分数高绕过。不能凭模型猜测用户最喜欢什么，需要真实反馈。返修分支保留原稿/未改前缀、清下游失效记录；新稿重审重锁仍可供写手读取。

世界手册只读批准设定，人物手册区分基线和实际选择，剧情档案区分计划与已发生后果，伏笔档案保留原承诺/期限并重放定稿事件。派生视图不另请模型写摘要，不自动把草稿写回基线。SHA256验证来源版本，不证明内容好看。档案异常可显示诊断，原稿仍可打开。

不照搬“十级修炼体系”“人物永不改变”“每章强反转”“固定口头禅”“反派永不转变”等通用硬指令；这些会把题材和人物压进同一模板。也不把单次批量生成七章替代逐章检查。
