# 独立安卓本机版 V0.10｜2026-10-17

## 已交付的范围

这是可独立安装的安卓测试版。界面、原V0.9创作引擎、参考文风、三章联合验收、十章总审、修订分支、锁定、导入导出与SQLite随App运行。模型直接连接供应商官方API。打开和运行不要求ChatGPT账户，也不调用原chatgpt.site工作台。

App使用设备内置WebView渲染随安装包附带的界面，原生组件处理数据库、HTTPS、通知、后台服务、设备保险箱和文件选择；没有远程网页作为主界面。

这是本机运行架构。关机、强行停止或进程被系统结束后不能继续创作。若需要手机关机后24小时执行，应另行部署独立服务器；本轮没有购买或部署服务器。

## 手机使用

1. 安装 `NovelFactory-0.10.0-Standalone.apk`。使用原0.4同一更新证书，可覆盖旧入口版本，无需先卸载。
2. 在App「模型设置」粘贴DeepSeek API Key。充值地址是余额管理页面，不能代替Key。Key只填App，不填聊天或GitHub。
3. 默认策划、主写和审核都设为DeepSeek V4 Pro，各自独立请求；可以只用一个Key。可手动改审核服务商，但程序不会自动替换或回退模型。
4. 核对模型单价和预算，之后由本人启用费用授权并保存。安装、导入、查看和采用既有文风不调用模型。
5. 创建作品，先选新增3章并启动本机自动任务。自动执行规划、写作、审核及最多三轮返修；质量门、预算、规则不符或异常会停止。
6. 通知栏显示运行状态并提供暂停。主动暂停后最多完成当前请求的检查点，不会开始下一次模型调用。
7. 从「模型设置」定期导出完整作品备份。卸载会删除本机数据。

## 锁屏与后台

使用用户主动启动的安卓前台dataSync服务及有限时长的唤醒锁，App返回桌面后不主动暂停引擎。锁屏时能否持续执行取决于系统、设备厂商、省电管理和网络。单次会话限制约5小时，达到上限暂停；这不是24小时不间断承诺。

Android官方说明：目标Android15+的dataSync前台服务在后台受24小时内累计6小时的限制，达到时限必须停止。本App设置更短会话并实现系统超时停止。不把前台服务当成规避系统限制的方法。

来源：https://developer.android.com/develop/background-work/services/fgs/timeout

## 旧网页作品迁移

在原私有工作台「模型设置 → 备份与恢复」下载完整作品JSON，再在本App同一入口选择文件导入。每部作品分别导出导入；保留正文、版本、事实和文风，恢复按原规则校验并保持暂停。

作品备份不含模型Key、旧调用账单或账户余额。本机费用记录从本机调用开始，预算和授权需在本App核对。不会自动复制云端密钥或后台启动旧任务。原网页、数据库和暂停的调度保留，本轮未改变。

## 自审与修正

- 原0.4是浏览器入口，本轮替换成随APK打包的界面和引擎，生产资源中无原Site地址或Cloudflare运行时导入。
- 旧安卓SQLite的JSON1不能作为前提，补兼容投影；主记录、预算条件和投影在同一事务，投影失败回滚原文及revision。
- 文件导出原先使用未挂到页面的下载链接，普通页面监听拿不到；补上原生文件保存入口。TXT/JSON导入使用系统选择器，不申请全盘存储权限。
- Activity重建复用原引擎，避免重载未完成付费调用。使用单任务入口，不让通知点击打开第二套引擎。
- 请求中断和进程恢复不自动重放；保留未知费用预留。服务启动失败会暂停新登记任务。
- 原生URL再次按协议、主机、方法、路径校验；拒绝任意代理、重定向、相似域名、本地地址及向GitHub携带模型Key。
- API Key在本机AES-GCM加密，运行密钥由Android Keystore包装；安装包不含Key或签名私钥，完整作品备份也不含Key。
