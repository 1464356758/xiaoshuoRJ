# AI商业小说工厂｜安装和模型接入教程

适用版本：V0.3；核对日期：2026-10-08。

软件：[打开创作工作台](https://ai-novel-factory.qq1464356758.chatgpt.site)。在线教程：网址后加 `/guide`，或侧栏「安装与教程」。私人小说不进入公开GitHub；请只在软件的密码输入框填写API密钥。

## 1. 安装成手机App

当前交付可安装的网页App（PWA）。它有手机桌面图标和独立窗口，仍使用云端数据库。这次没有交付原生Android APK。

1. 安卓用Chrome或支持PWA安装的浏览器打开软件网址。登录自己的ChatGPT账号。
2. 点击软件右上角「安装App」。如果浏览器未弹安装框，打开浏览器菜单，选「安装应用」或「添加到主屏幕」。
3. 按提示确认，然后从桌面的「小说工厂」图标打开。
4. 微信、QQ或聊天工具内置网页通常不提供完整安装功能。先将网址在外部浏览器打开。
5. iPhone用Safari打开，分享菜单 →「添加到主屏幕」。电脑可使用浏览器地址栏的安装图标。

安装不是后台运行的前提。网络断开时不能查看云端稿件；已启动任务不会因关闭手机页面而被取消。本机未同步的编辑输入会保留临时副本，重要稿件仍建议定期下载完整备份。

## 2. 接入豆包

这里接的是火山引擎「火山方舟」API，不是豆包聊天App、聊天App密码或Coding Plan专属接口。使用自己的API账户；软件不会替你充值、订阅或购买算力。

1. 打开[火山方舟控制台/API Key管理](https://ark.volcengine.com/region:cn-beijing/apikey)，注册或登录。按平台当前要求完成验证。
2. 在「API Key管理」创建并复制API Key。把Key当成密码保存，不发聊天，不放截图，不写入GitHub。
3. 到「开通管理」查看已经允许使用的文本模型。复制完整的Model ID。也可以使用你已经创建的推理接入点Endpoint ID，通常以 `ep-` 开头。不要把展示名称「豆包」当成ID。
4. 回到小说工厂的「模型设置」，选「豆包 / 火山方舟」。在「策划 / 默认模型」粘贴ID，在「API密钥」粘贴Key。写作和审核模型暂时留空，沿用默认模型。
5. 核对[官方模型价格](https://docs.volcengine.com/docs/ark/model-pricing?lang=zh)和控制台。填输入、输出最高单价，单位统一是人民币/百万token。如果来源单位是元/千token，要乘1000。缓存未命中价、长上下文档位、不同所选模型中的最高价都应纳入。
6. 将「模型最大输出token」设置为所选模型实际支持的上限。系统会取它与当前任务所需上限的较小值；规划和全文修订需要比连接测试更长的输出。
7. 填单次、单书、月度费用上限。先保持小预算，不要直接批量生成全书。免费体验额度不等于永久免费价格。
8. 勾选费用授权，保存配置。点击「测试连接（可能计费）」。该测试最多请求64个输出token，仍按真实API规则计费，并受预算限制。
9. 看到接口JSON连接成功后，再创建作品并做策划或开篇。接口连接成功不能证明模型写作质量或签约竞争力。

接口地址由程序固定为 `https://ark.cn-beijing.volces.com/api/v3`，路径是 `/chat/completions`，你不用输入。程序使用API Key的Bearer鉴权、JSON响应、`max_completion_tokens`限制总输出，并使用 `thinking.type=disabled` 关闭深度思考以控制预算。请选择官方支持这些参数的现代文本模型；旧模型、翻译、视频、语音专用模型不适合这个流程。控制台模型和价格会变，复制当前可用ID，不照抄过期攻略。

官方依据：[快速入门](https://docs.volcengine.com/docs/ark/quick-start?lang=zh)、[Chat API](https://docs.volcengine.com/docs/ark/chat-api?lang=en)、[输出长度控制](https://docs.volcengine.com/docs/ark/context-management?lang=zh)、[深度思考开关](https://docs.volcengine.com/docs/ark/deep-thinking?lang=zh)。

## 3. 接入其他模型

所有服务商的操作顺序都是：创建API Key → 复制可用文本模型ID → 在软件中选服务商、填模型和Key → 核实价格 → 保存预算和授权 → 小额连接测试。

| 软件选项 | 获取凭据 | 模型ID要点 | 官方说明 |
|---|---|---|---|
| DeepSeek | [开放平台](https://platform.deepseek.com/) | 使用控制台当前可用的文本模型ID | [接口文档](https://api-docs.deepseek.com/en/) |
| 豆包 / 火山方舟 | [API Key管理](https://ark.volcengine.com/region:cn-beijing/apikey) | 已开通Model ID，或支持所需参数的Endpoint ID | [快速入门](https://docs.volcengine.com/docs/ark/quick-start?lang=zh) |
| OpenAI | [API Keys](https://platform.openai.com/api-keys) | 选择支持Chat Completions的文本模型；部分推理模型不能传普通采样参数 | [官方接口说明](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create) |
| OpenRouter | [API Keys](https://openrouter.ai/settings/keys) | 填完整的提供方/模型ID，保留斜杠 | [快速入门](https://openrouter.ai/docs/quickstart) |
| 硅基流动 | [API密钥](https://cloud.siliconflow.cn/account/ak) | 从模型广场复制完整名称，保留大小写和斜杠 | [快速上手](https://docs.siliconflow.cn/docs/userguide/quickstart) |
| Kimi / Moonshot | [开放平台](https://platform.moonshot.cn/) | 填平台当前可用的文本模型；不同版本参数存在差异 | [快速开始](https://platform.moonshot.cn/docs/guide/start-using-kimi-api) |
| Groq | [API Keys](https://console.groq.com/keys) | 从模型列表复制当前可用ID，核实上下文/输出长度和限流 | [兼容说明](https://console.groq.com/docs/openai) |

当前一次创作使用一个服务商。策划、写作、审核可选这个服务商内的不同模型；留空写作和审核模型则沿用默认模型。当前尚未实现跨服务商同时组合调用，也不支持任意自定义接口地址或直接连接手机本地模型。

切换服务商会清空界面里的模型、价格和授权；重新填入该平台的Key并保存。某个平台的Key不能用于另一家。服务器不会把旧平台Key带入新平台，也不会向页面或备份返回它。其他模型可能有特殊参数、能力或输出限制，兼容入口并不保证所有型号都适合完整小说流程。

输入和输出分别填写所有选中模型中的最高单价。美元价格先按你核实的汇率转换成人民币。OpenAI API、ChatGPT订阅是分开计费的产品；其他聊天会员也不应被当作API额度。软件费用账目是按配置价格核算，应定期与供应商实际账单核对。未知用量和中断请求保留费用预留，不会假装免费。

## 4. 云端自动写作

1. 创建作品，设定创作方向、主平台、总章节、每章目标字数和单书预算。默认支持100章、每章9000汉字；也可先用较短章节验证。
2. 超过10章的长篇先比较选题、保存故事圣经与覆盖全书的阶段，再每批规划最多10章。界面显示已保存计划数，可展开查看故事和阶段；全书章节计划齐全前不会开始正文。已完成完整大纲的旧作品直接续写。中断只补缺失批次，未完成规划也在完整备份中。分批会增加少量规划请求，以降低一次输出截断的风险，仍受你的预算约束。
3. 在控制台选择「本轮新增3章」「本轮新增10章」或「持续至全书完成」，点击「启动云端创作」。这一步登记服务器持久任务，不要求页面保持打开。
3. 当前托管调度每小时唤醒一次，时区Asia/Shanghai；每轮最多80个检查点或20分钟。一个检查点可能是策划、场景合同、正文片段、审核或返修准备。长章通常有多个片段。
4. 想立即推进时，点击「立即推进一步」。它只做一个检查点；之后即使关闭App，已登记任务仍会由云端分批继续。
5. 重新打开查看任务状态、目标、已保存片段、审核、费用、最近执行和调度心跳。页面每8秒读取进度，读取不会启动模型。
6. 达到目标即完成本轮。预算不足、模型请求失败、质量门或阶段审核失败会阻塞任务；修订最多三轮，不会不断重试消耗费用。
7. 异常进程中断后，过期租约允许下一次调度恢复；已保存片段不会重复生成。若供应商已受理但结果未保存，该次用量无法确定，保留预留费用，不能保证供应商完全不计费。

云端是定时分批推进，不能承诺24小时无间隔、固定出稿速度或永不宕机。平台任务额度、限流和模型可用性会影响运行。没有任务或未授权模型费用时，不调用模型。不自动公开发表、签署合同或接受独家授权。

## 5. 查看进程和控制大纲

1. 在「创作控制台」查看当前检查点、章节/片段、定稿数量、目标、日志、错误和费用。
2. 要改稿或大纲，先点「暂停」。已在执行的请求最多完成当前检查点，不会开始下一次请求。等待保存结束。
3. 进入「小说工作室 → 大纲与人物 → 编辑未来大纲」。可输入整体后续方向，逐章修改尚未开始的标题、剧情目标、冲突解决方式和实际后果；也可修改未开始阶段的目标、不可逆变化。
4. 已开始的章节合同、已开始的阶段和正式锁定事实受保护。大纲编辑不是删除已有正文，也不能随意改变人物已经经历过的事实。
5. 保存后生成新的大纲版本，旧版可查看并进入完整备份。新要求从下一项尚未开始的章节生效。
6. 检查方向后重新启动云端任务。修改模型配置也会使旧任务阻塞，避免后台静默更换模型和预算。
7. 正文编辑保留历史版本；定稿需要重新审核，已有后章时不允许直接解锁破坏前章事实。

## 6. 常见问题

| 提示 | 处理 |
|---|---|
| 401 | 检查Key是否完整、有效、属于所选服务商。不要发送Key到聊天。 |
| 403 / 404 | 检查模型权限、开通状态、完整ID和接口兼容性。 |
| 429 | 检查调用速率、服务商额度；稍后手动重新启动。系统不无限重试。 |
| 本次最高预留超过单次上限 | 核对最高单价和输出上限。确有必要时再提高预算，不要靠填虚假0价绕过。 |
| 月度或单书额度不足 | 查看含待核对预留的账目。先暂停，在「模型设置」调整当前作品预算和全局单书上限，保存后再自行启动；降低预算不清除历史费用。 |
| JSON缺失、输出截断 | 调整规划规模、最大输出token或所选模型；不完整结果不会覆盖已存正文。 |
| 任务被配置或大纲变化阻塞 | 检查新配置，确认方向后重新启动；旧任务不会静默使用新设置。 |
| 审核失败/架构问题 | 查看原文证据和诊断，修改故事结构，不降低85分门槛或无限返修。 |
| 安装按钮只显示说明 | 用外部浏览器打开，并检查浏览器安装菜单；PWA安装能力因浏览器而异。 |

「模型设置」下方可修改当前作品预算。先暂停并等待检查点结束；保存预算不会开启费用授权或恢复任务。你需要另行检查并启动。月度、全局单书和单次上限仍共同约束调用。

定期在「小说工作室」或「模型设置」下载完整JSON备份。它包含规划、正文、审核、章节版本、大纲历史、故事状态，不含API密钥。TXT导出默认只包含已定稿章节；下载本机草稿不等于正式定稿。恢复备份创建独立副本并默认暂停，不覆盖原作品。

## 7. 验证边界

软件流程、恢复、预算和故障路径使用真实SQLite、合成测试夹具验证；这种测试不能代表文学质量。没有提供可用真实模型API之前，真实豆包响应、开篇三章、手机实机安装和商业签约竞争力仍需实际验证。签约和收入不能保证。
