# 旧故障 → V2设计 → 实际测试

| 用户报告/旧问题 | V2处理 | 已验证结果 |
|---|---|---|
| 第一章长时间无法完成/循环 | 保存阶段，独立规划、一次完整正文、最多五次有效审核 | 44项中合成三阶段完整成稿、五次78分后按实分收稿通过 |
| 总是78/原有内容被当新增 | 六维本地求和、维度增减、旧问题保留、全文及真实diff | 等总分维度变化、旧位置/原稿已有引文不能关闭问题通过 |
| 总监返修指令空泛 | 本地消费具体问题、段落ID/hash、改法与验收条件 | 4轮返修4HTTP，总监0；越界/同稿/标点补丁拒绝并保留候选 |
| 保存/模型/Key按钮故障 | 独立原生表单、CAS、就近错误、草稿保护、加密保存 | 真HTTP保存/回读/冲突/继承通过；原生编译通过，手机实机待验 |
| 停止后还请求 | 先事务代次失效，再Abort；共享出口 | 排队、意图后、HTTP前后、响应后、返修与复审之间停止通过 |
| 重启/手机退出导致重复 | 稳定业务步骤键、持久意图；未知停机 | 并发/换nonce、手机关闭模拟、SIGKILL五边界恢复通过 |
| 一小时1600次/约50元 | 原报告保留待官方逐笔对账；V2统一真实请求台账与共享频率 | 1600实际控制GET零模型HTTP；6/min等待通过；该测试不解释历史供应商账单 |
| 旧金额门阻塞 | 金额门强制关闭，单价只记账 | 空价格、上限0、历史金额不限制请求；unknown不虚构扣费 |
| 数据丢失/审核清零 | 私有物理备份、独立库、完整旧记录归档、真实计数迁移 | 合成SQLite完整性/备份、4/5审保留与恢复默认暂停；生产回读待切换 |

所有供应商均为明确标注的合成HTTP服务器。程序测试不证明文学改善、真人阅读或签约，也未调用真实DeepSeek。
